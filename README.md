# Apple Price Prediction & Communication Platform
> **기상 데이터 기반 사과 가격 예측 AI 및 PHP 기반 커뮤니티 관리 시스템**

본 프로젝트는 **데이터 기반 농산물 가격 예측 서비스**와 **사용자 소통 및 운영 관리 기능을 갖춘 커뮤니티 플랫폼**을 통합한 솔루션
기상청 및 공공데이터를 활용해 사과 가격 변동을 분석하고, 예측 결과를 웹 서비스 형태로 제공하며, 동시에 PHP/MySQL 기반의 게시판 및 회원 관리 시스템을 통해 사용자 참여와 운영 편의성을 강화

---

## 1. 솔루션 개요

### 1-1. 개발 배경
사과와 같은 농산물은 기상 조건에 따라 생산량과 가격 변동 폭이 크게 달라짐  
이에 따라 단순 시세 확인을 넘어, **기상 데이터와 시장 데이터를 기반으로 가격 흐름을 예측**할 수 있는 서비스의 필요성을 느껴 본 프로젝트를 기획

또한 예측 정보가 일방적으로 제공되는 데 그치지 않고, 사용자들이 정보를 공유하고 소통할 수 있도록 **커뮤니티 및 관리자 기능을 포함한 통합형 플랫폼**으로 확장

### 1-2. 개발 목적
- 기상 및 유통 데이터를 기반으로 사과 가격을 예측하는 AI 서비스 구현
- 예측 결과를 웹 기반 UI로 제공하여 사용자 접근성 향상
- 회원 관리, 게시판, 관리자 기능을 포함한 커뮤니티 시스템 구축
- 데이터 기반 정보 제공과 사용자 참여 기능을 결합한 통합 플랫폼 구현

### 1-3. 구성 모듈
본 프로젝트는 다음 두 가지 핵심 모듈로 구성

#### ① 사과 가격 예측 서비스
기상청 기상 데이터와 Kamis 오픈 API 데이터를 활용하여 사과 가격의 변동 패턴을 분석하고, 예측값을 웹에서 확인할 수 있도록 구현한 서비스

#### ② 커뮤니케이션 및 관리 시스템
PHP와 MySQL 기반으로 회원 가입, 로그인, 게시판, 댓글, 관리자 기능 등을 제공하는 커뮤니티 운영 시스템

## 2. 주요 기능 정의

### 2-1. 사과 가격 예측 서비스
- 기상 데이터와 농산물 유통 데이터를 수집 및 분석
- 기온, 강수량 등의 입력값을 기반으로 사과 가격 예측
- 데이터 정규화 및 학습을 통한 예측 모델 성능 개선
- Flask 기반 웹 페이지에서 예측 결과 실시간 출력
- 사용자 친화적인 입력 폼 및 결과 확인 UI 제공

### 2-2. 회원 관리 시스템
- 회원가입, 로그인, 로그아웃 기능 제공
- 비밀번호 단방향 암호화 저장
- 아이디 및 이메일 중복 검사
- 우편번호 API 연동
- 프로필 이미지 미리보기 기능 제공

### 2-3. 커뮤니티 게시판
- 게시글 작성, 수정, 삭제 및 조회
- 파일 첨부 기능과 업로드 용량 제한 처리
- 댓글 등록 및 사용자 간 상호작용 지원
- 게시글 검색 기능 제공
- 조회수 중복 증가 방지 처리

### 2-4. 관리자 기능
- 회원 목록 조회 및 권한 관리
- 게시판 데이터 페이지네이션 처리
- 회원 및 게시글 데이터 Excel 저장
- 동적 게시판 생성 및 삭제 기능 제공
- 커뮤니티 운영 효율성을 위한 관리자 전용 기능 구현

## 3. 데이터 및 기술 활용

### 3-1. 데이터 활용
- **기상청 기상 데이터**  
  사과 생산 및 가격에 영향을 주는 기온, 강수량 등의 데이터를 활용

- **Kamis(농수산유통정보) 오픈 API**  
  사과의 실제 유통 가격 데이터를 수집하여 예측 모델 학습에 활용

### 3-2. AI 예측 서비스 기술 스택
- **Language:** `Python 3`
- **Environment:** `Jupyter Notebook`, `Anaconda`, `VS Code`
- **Libraries:** `Pandas`, `Scikit-learn`, `Flask`
- **Model Concept:** 경사 하강법(Gradient Descent), MSE(Mean Squared Error)

### 3-3. 데이터 처리 및 모델 개선
- `StandardScaler`를 활용하여 기상 데이터(기온, 강수량)를 정규화
- 손실 함수(Loss) 값을 초기 **약 57만**에서 **17~18만** 수준으로 낮추어 약 **68% 개선**
- 최적화 알고리즘을 기존 SGD에서 **Adam**으로 변경하여 학습 수렴 속도와 예측 정확도 향상
- 학습된 모델을 Flask 웹 서비스와 연동하여 실사용 가능한 형태로 구현

### 3-4. 커뮤니티 시스템 기술 스택
- **Backend:** `PHP`
- **Database:** `MySQL`
- **Server:** `XAMPP (Apache)`
- **Frontend:** `HTML5`, `CSS3`, `JavaScript`
- **DB Tool:** `SQLyog`

## 4. 시나리오

### 시나리오 1. 가격 예측 서비스 이용
1. 사용자는 웹 페이지에 접속
2. 기온, 강수량 등 필요한 값을 입력
3. 시스템은 입력값을 정규화한 뒤 학습된 모델에 전달
4. 예측된 사과 가격 결과를 화면에 출력
5. 사용자는 이를 참고하여 가격 흐름을 확인할 수 있음

### 시나리오 2. 커뮤니티 이용
1. 사용자는 회원가입 후 로그인
2. 게시판에 글을 작성하거나 다른 사용자의 글을 조회
3. 댓글을 통해 의견을 남기고 정보를 공유
4. 파일 첨부 기능을 활용해 관련 자료를 업로드

### 시나리오 3. 관리자 운영
1. 관리자는 관리자 페이지에 접속
2. 회원 목록을 확인하고 권한을 관리
3. 게시판 운영 현황을 확인하고 필요한 게시판을 생성 또는 삭제
4. 회원 및 게시판 데이터를 Excel 파일로 저장하여 관리 업무에 활용
